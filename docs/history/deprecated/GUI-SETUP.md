# Browser GUI retired

> **Deprecated interface — not current implementation guidance.** Preserved for provenance.
> See [documentation status](../../README.md) and the current [roadmap](../../HEIMDALL-IMPLEMENTATION-ROADMAP.md).
> Dates, versions, “current” claims and commands below describe the original review.

The browser frontend and its sign-in/session routes have been removed in favor
of the new terminal design. `heimdall ui` now opens the TUI.

See [Terminal workstream setup](../../guides/TUI-SETUP.md) for startup, keyboard controls,
progress review, retained drafts and compact display. Historical GUI review
events remain replayable; old browser URLs and sign-in codes are no longer used.
